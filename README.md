# 🚗 Speedy Car - Android Racing Game

Welcome to **Speedy Car**, a fast-paced Android racing game where your reflexes are tested! Dodge traffic, collect coins and diamonds, and extend your racing time in this thrilling arcade experience.

## 🚀 Features

- Simple, intuitive controls
- Endless driving with increasing difficulty
- Collect coins and diamonds to gain more time
- Dynamic background and car speed changes
- Leaderboard integration (coming soon)
